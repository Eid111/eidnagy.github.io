# Eid Nagy Portfolio

موقع ثابت يعمل على GitHub Pages، من دون Python أو خادم خلفي. محتوى الموقع محفوظ في `site-data.json`.

## النشر على GitHub Pages

1. ارفع محتويات هذا المجلد إلى جذر مستودع GitHub باسم `USERNAME.github.io`.
2. من **Settings → Pages** اختر النشر من الفرع الرئيسي `main` ومجلد الجذر `/root`.
3. بعد اكتمال النشر افتح `https://USERNAME.github.io`.
4. لوحة الإدارة: `https://USERNAME.github.io/admin.html`.

يمكن تجربة الموقع محلياً بفتح المجلد في VS Code وتشغيل **Live Server** على `index.html`. لا تفتح ملفات HTML مباشرة عبر `file://` لأن المتصفح يمنع تحميل ملف البيانات بهذه الطريقة.

## لوحة الإدارة

1. أنشئ **Fine-grained personal access token** من إعدادات GitHub، وحدد المستودع المطلوب فقط وصلاحية **Contents: Read and write**.
2. افتح `admin.html`، وأدخل اسم مالك المستودع واسمه والفرع (غالباً `main`) والرمز.
3. الرمز يبقى في ذاكرة الصفحة فقط ولا يُحفظ في ملفات المشروع أو تخزين المتصفح. لا تشاركه ولا تضعه في الموقع.
4. تعديلات البيانات تُحفظ كـ commit إلى `site-data.json`، ثم ينشر GitHub Pages النسخة المحدّثة تلقائياً.

أضف الفيديوهات كرابط YouTube أو رابط HTTPS مباشر؛ لا ترفع ملفات فيديو كبيرة إلى مستودع الموقع. نموذج التواصل يفتح رسالة جاهزة في واتساب ولا يخزّن الرسائل، لأن GitHub Pages لا يشغّل قاعدة بيانات أو خادماً.
